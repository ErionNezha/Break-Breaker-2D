# 🧱 Break-Breaker-2D

Krijuar nga **Erion Nezha** — © 2026

Loja klasike **Breakout / Brick-Breaker** 2D, e shkruar në JavaScript + HTML5 Canvas.

## 🎬 Demo live

https://erionnezha.github.io/Break-Breaker-2D/

## 🕹️ Si luhet

- **Shigjetat ← →** — lëviz paddle-in
- **Mouse** — paddle ndjek kursorin
- **Touch** — rrëshqit gishtin (mobile)
- Kliko / tap për të nisur lojën

Thyeji **28 tullat** për të fituar. Nëse topi bie poshtë paddle-it, loja mbaron.

## 📁 Origjinali

`original/` përmban kodin burim të paprekur: `index.html`, `app.js`, `styles.css`, `README.md`.

## 🛠️ Përshtatja për web

Demo-ja (`demo/index.html`) ndjek logjikën e `app.js` origjinal: topi, paddle, tullat 7×4,
kolizionet dhe sistemi i pikëve. U shtuan: ekrani i nisjes, fitore / game-over pa `alert`,
kontroll me touch për mobile, dhe UI në shqip.
